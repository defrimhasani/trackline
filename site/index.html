Every worklog, where it actually happened.

Trackline reads your Jira worklogs and lays them out as a week or month calendar. The timeline stretches for the 07:30 start and the late fix, and entries that overlap sit side by side instead of hiding each other.

Week and month views · weekends hidden by default

Click an hour. It’s logged in Jira.

Point at the calendar and a 15-minute slot follows the cursor. Click it, then pick the issue from Recent activity or Recently viewed, or search all of Jira by summary or key. Set the duration, day, start time and a description, and the worklog is written straight to Jira.

Jira issue-type icons, so bugs still look like bugs.

The days you missed, in coral.

Turn on Focus on incomplete days and every working day below your target lights up with exactly how much is missing. Complete days and days that haven’t happened yet step back.

Your target is your workday length: 8 hours unless you change it.

Your team’s week, one grid.

Choose Jira projects and pin teammates to see people by days. Pinned people appear even when they logged nothing, which is usually the point. Click any cell to read that person’s worklogs for the day, with the same incomplete-day focus.

Try a cell on the replica.

Every ticket, costed.

Switch the team view to Tickets. Each row shows the work type, whether the work is capitalized or a cost, the hours logged this week, the total against its estimate, and who logged the time.

The bar above the table splits the week into capitalized and cost hours, so the finance question already has an answer.

Trackline finds your Work type and Cost/Capitalized fields by name. You can change them in Settings.

A CSV when someone asks for one.

Export your own worklogs, or a team summary, every worklog line and per-ticket totals as three files. They’re saved to your Downloads folder, named for the period.

  • trackline-team-summary-2026-03-09_2026-03-15.csv
  • trackline-team-worklogs-2026-03-09_2026-03-15.csv
  • trackline-team-tickets-2026-03-09_2026-03-15.csv

A side panel that keeps today honest.

Today’s pulse shows your hours against the target, with a one-click way to log the missing time. Needs attention lists the incomplete days. Recently worked opens the issue in Jira.

Pick a time for the daily reminder. On weekdays, if you’re below target, Trackline sends a native notification. It works while the app is running.

Small things, done properly.

Week and month
A timetable of your week, or a month grid with daily totals and the issues behind them. Click the month name to jump to any month.
Overlaps side by side
Two worklogs in the same hour share the slot instead of stacking on top of each other.
A timeline that stretches
An early start or a late finish widens the hours shown, so nothing falls off the edge.
Hide weekends
On by default. Turn it off if Saturday work is part of your week.
Your workday length
Eight hours unless you say otherwise. Every target and missing-time badge follows it.
Issue-type icons
The same icons Jira uses, so a bug in the picker looks like a bug.
Light and dark
Two themes for the room you work in, and Trackline remembers your choice. The moon on the replica above switches it.
A resizable window
A native desktop window you can size and place around the rest of your work.

Your computer talks to your Jira. That’s the whole route.

Trackline has no server in the middle. Requests go straight from your machine to your Jira Cloud site, using your own Atlassian API token.

Your computerTrackline app
Trackline serverdoesn’t exist
your-team.atlassian.netYour Jira Cloud site
  • No account, no analytics. Nothing to sign up for, nothing reported back.
  • Your token stays in your OS vault. Built apps keep it in the system credential store, such as macOS Keychain.
  • Only what your account can do. Trackline sees and changes exactly what your Jira user can, nothing more.

Running in development with npm run tauri dev? Credentials are kept in a local, git-ignored file with owner-only permissions instead.

Connect Jira in three steps.

  1. 1
    Create an API token

    At id.atlassian.com → Security → API tokens.

  2. 2
    Enter your details in Settings

    Your Jira site address, your Atlassian email and the token.

  3. 3
    Select Connect Jira

    Then Refresh calendar, and the worklogs you already have load from Jira.

Opening it the first time

Trackline isn’t signed with a paid Apple or Microsoft certificate yet, so your system asks you to confirm once.

  • macOS: open Trackline, then go to System Settings → Privacy & Security and select Open Anyway.
  • Windows: in the SmartScreen prompt, select More info → Run anyway.

After that, Trackline keeps itself up to date. It checks for new versions and asks before installing.

Or build it yourself.

Trackline is open source. Building it from source on macOS, Windows or Linux takes four commands.

  • Node.js 20 or newer
  • Rust, stable
  • The Tauri prerequisites for your OS
Terminal
git clone https://github.com/defrimhasani/trackline.git
cd trackline
npm install
npm run tauri dev

Want an app you can install? npm run tauri build writes a bundle to src-tauri/target/release/bundle/.
